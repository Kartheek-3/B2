# B2 Project

## Project Overview
This repository contains data, analysis, code, and experiments divided into distinct phases/parts.

## Directory Structure
```
B2/
│
├── README.md
├── data/
├── code/
├── test_result/
│
├── Part1/
│   ├── patterns.csv
│   ├── Pattern_count.csv
│   ├── pattern_architecture/
│   ├── Part1_prompt.txt
│   └── llm.csv
│
├── Part2/
│
└── Part3/
```

### Components
- **`data/`**: Raw and preprocessed input datasets.
- **`code/`**: Source code, processing scripts, and model pipelines.
- **`test_result/`**: Evaluation metrics, benchmark outputs, and experiment logs.
- **`Part1/`**:
  - `patterns.csv`: Identified or target design/architecture patterns.
  - `Pattern_count.csv`: Frequency or distribution metrics for patterns.
  - `pattern_architecture/`: Architecture diagrams, schemas, or specifications.
  - `Part1_prompt.txt`: LLM prompt templates and instructions for Part 1.
  - `llm.csv`: LLM outputs, predictions, or evaluation records.
- **`Part2/`**: Reserved for Phase 2 workflows and analyses.
- **`Part3/`**: Reserved for Phase 3 workflows and analyses.
