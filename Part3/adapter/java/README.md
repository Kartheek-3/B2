# Adapter Pattern - Java Implementation

## Environment
- Runtime/Compiler: Java 17/21

## How to Compile and Run
Run the following from this directory:
```bash
javac -d bin snippet/*.java snippet/models/*.java tests/*.java && java -cp bin test.AdapterTest
```

## Pattern Details
Provides an equivalent implementation of the adapter pattern. The source logic matches the defined contract and edge cases (time offsets, error mapping).
