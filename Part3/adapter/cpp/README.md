# Adapter Pattern - Cpp Implementation

## Environment
- Runtime/Compiler: GCC 15.2

## How to Compile and Run
Run the following from this directory:
```bash
wsl -e bash -c "g++ -std=c++14 -o tests/test_adapter tests/test_adapter.cpp && ./tests/test_adapter"
```

## Pattern Details
Provides an equivalent implementation of the adapter pattern. The source logic matches the defined contract and edge cases (time offsets, error mapping).
